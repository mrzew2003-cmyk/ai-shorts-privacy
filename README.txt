AI Shorts Automation – GitHub Pages starter

1. Replace REPLACE_WITH_YOUR_SUPPORT_EMAIL in index.html and privacy.html with the email address users can contact.
2. Create a PUBLIC GitHub repository named: ai-shorts-privacy
3. Upload index.html and privacy.html to the repository root.
4. In GitHub, open Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish the site.

Expected URLs:
Homepage: https://mrzew2003-cmyk.github.io/ai-shorts-privacy/
Privacy policy: https://mrzew2003-cmyk.github.io/ai-shorts-privacy/privacy.html

Important:
- These URLs work only after the repository is created and GitHub Pages is enabled.
- Confirm the pages load publicly in a private/incognito browser window.
- In Google Auth Platform -> Branding, enter the actual homepage and privacy policy URLs.
- Make sure the policy accurately reflects the app's real data handling. Update it if tokens or user data are sent to a server or third-party service.
- Google may require domain ownership verification and additional verification depending on OAuth scopes and app configuration.
